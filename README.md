# CodeMind

AI-Powered Software Engineering Intelligence Platform.

CodeMind is a full-stack AI platform that helps developers understand
software repositories and technical documentation using LLMs, RAG,
semantic search, and AI agents.

## Tech Stack

### Frontend
- Next.js
- TypeScript
- Tailwind CSS

### Backend
- FastAPI
- Python
- SQLAlchemy

### Database
- PostgreSQL
- pgvector

### Infrastructure
- Docker
- Redis
- RabbitMQ
- Kafka

### AI
- LLMs
- Embeddings
- RAG
- Reranking
- AI Agents
